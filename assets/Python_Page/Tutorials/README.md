## How to Use

1. **Open in Google Colab:**
   - Upload `.ipynb` files to Colab
   - Or use "Open in Colab" feature

2. **Run Cells:**
   - Execute code blocks with `Shift+Enter`
   - Experiment with modifications

3. **Practice:**
   - Try solving problems before viewing solutions
   - Add your own test cases

## Tips for Success

- Try problems yourself before looking at solutions
- Experiment with code modifications
- Read error messages carefully
- Do not just copy-paste solutions
- Do not skip the fundamentals
